# Publication checklist

- Read the full tutorial and verify you can explain the code and the physics in your own words.
- Run the new final export cell in the completed Colab session and retain its runtime ZIP. Download the notebook separately with outputs.
- If the session has disappeared, restore the earlier data checkpoint and rerun; do not reconstruct missing catalog data from displayed output.
- Keep the exact raw sample, query, partition IDs, version record, trained model, and predictions together for reproducibility.
- Add the real runtime artifacts to your distribution as appropriate; the supplied starter package does not contain them.
- Review rendered notebook and README in GitHub. Include tutorials and explanatory notes as planned.
- Include appropriate SDSS attribution. Choose a code license before publishing if desired; none has been assigned automatically.
- Use final test metrics and acknowledge the sample limits. Do not tune using this already-opened test set.
- When you are comfortable explaining the completed project, prepare your résumé entry and repository link.
